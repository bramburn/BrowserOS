# `resources/icons/chromeos/` — ChromeOS / webstore icon set

> Part of [`../../AGENTS.md`](../../AGENTS.md) in
> [`resources/icons/`](../../AGENTS.md).

## What's here

Five PNGs covering the ChromeOS launcher icon, the crosh (terminal) icon,
and the two Chrome Web Store listing sizes. They are generated by
`build/scripts/icon_generation/generate_icons.py` and copied as a whole
directory to `chrome/app/theme/chromium/chromeos` by the
`ChromeOS Icons` entry in `build/config/copy_resources.yaml`.

## Contents

| File | Size | Purpose |
|---|---|---|
| `chrome_app_icon_32.png` | 32 | ChromeOS launcher icon, 1x |
| `chrome_app_icon_192.png` | 192 | ChromeOS launcher icon, launcher-size |
| `crosh_app_icon_256.png` | 256 | crosh terminal shortcut icon |
| `webstore_app_icon_16.png` | 16 | Chrome Web Store listing, small |
| `webstore_app_icon_128.png` | 128 | Chrome Web Store listing, large |

## Rules

**CO1 — Filenames are fixed by Chromium's ChromeOS code.** The names
`chrome_app_icon_32` / `chrome_app_icon_192` / `crosh_app_icon_256` /
`webstore_app_icon_16` / `webstore_app_icon_128` are read by name from
`chrome/app/theme/chromium/chromeos/`. Renaming produces a missing icon at
runtime, not a build error.

**CO2 — This is the only icon subdirectory without a DPI variant.** There
is no `default_100_percent` / `default_200_percent` counterpart, and no
`os:` filter on the copy operation — the whole directory goes into every
build.

**CO3 — Regenerate, never hand-edit.** All five files come from
`generate_icons.py`; see [`../AGENTS.md`](../AGENTS.md) IC1.

**CO4 — The copy is unconditional.** The `ChromeOS Icons` operation in
`copy_resources.yaml` has no `os`/`arch`/`build_type` filter, so a Linux or
macOS build also receives this directory. Do not assume removing it is
harmless on other platforms.

## Workflows

**Updating the ChromeOS launcher icon**
1. Update the source artwork under
   `build/scripts/icon_generation/source/`.
2. Run the generator; confirm all five files in this directory changed.
3. Run `browseros build -m resources` and check the `ChromeOS Icons` line.

**Verifying these actually reach the Chromium tree**
1. Check
   `<chromium_src>/chrome/app/theme/chromium/chromeos/` after phase 2.
2. Five files should be present; the directory copy uses
   `shutil.copytree(..., dirs_exist_ok=True)`, so stale extras are not
   removed — delete them from the checkout if a file is renamed.
