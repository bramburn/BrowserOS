# `resources/icons/default_200_percent/` — 200 % DPI icon set

> Part of [`../../AGENTS.md`](../../AGENTS.md) in
> [`resources/icons/`](../../AGENTS.md).

## What's here

The 2x (HiDPI) variants of the product logo — four files, no subdirectories.
The whole tree is copied to `chrome/app/theme/default_200_percent/chromium`
by the `DPI 200% Icons` entry in `build/config/copy_resources.yaml`, the
sibling of the 100 % destination.

## Contents

| File | Notes |
|---|---|
| `product_logo_16.png` | 1702 bytes — 2x of the 16px icon |
| `product_logo_32.png` | 3812 bytes — 2x of the 32px icon |
| `product_logo_name_22.png` | 2432 bytes — 2x of the 22px titlebar lockup |
| `product_logo_name_22_white.png` | 2432 bytes — 2x white silhouette |

## Rules

**D1 — Same nominal sizes as the 100 % tree, 2x pixels.**
`product_logo_name_22.png` is 2432 bytes here vs 1081 bytes in
`../default_100_percent/`. The *filename* stays the same; only the pixel
dimensions double. Renaming to `product_logo_name_44.png` breaks the lookup.

**D2 — There is no `linux/` subdirectory here.** The 100 % tree has one
(`../default_100_percent/linux/`); this tree does not, and no generator
rule produces one. Adding files requires editing
`build/scripts/icon_generation/generate_icons.txt` first.

**D3 — White variant is a `MONO` output, not a tinted copy.** It comes from
the generator's `MONO` operation; its byte size matching the colour variant
is incidental.

**D4 — Do not hand-edit.** Everything is regenerated by
`build/scripts/icon_generation/generate_icons.py`.

## Workflows

**Changing the HiDPI logo**
1. Update `source/app_icon.png` (≥1024×1024) under
   `build/scripts/icon_generation/source/`.
2. Regenerate; confirm all four files here and all four in
   `../default_100_percent/` changed in the same run.
3. Run `browseros build -m resources` and check the `DPI 200% Icons` line.

**Adding a 2x size**
1. Add a `PNG <source> <size> product_logo_<n>.png` line to `generate_icons.txt`
   (the generator derives 1x and 2x pairs from one source size).
2. Regenerate and check both DPI trees.

**Verifying placement**
1. After phase 2, check
   `<chromium_src>/chrome/app/theme/default_200_percent/chromium/`.
